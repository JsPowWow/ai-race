# 0005. Декор — только картинка

Статус: принято.

## Контекст

Вокруг трассы появились ёлки, круглые деревья и домики (`engine/world/scenery.ts`), а потом будет вид из машины. Сразу возникает вопрос: «почему луч проходит сквозь ёлку?» — или, наоборот, «давайте деревья будут препятствиями». Исследование — `docs/research/вид-из-кабины.md`.

## Решение

- **Декор не попадает в `track.segs`**, его не видят сенсоры (`castSegment`), об него нельзя разбиться. Физика, входы мозга, боты, старые файлы машин и честность финала от декора не зависят.
- **Декор стоит за бордюрами**: не ближе `SCENERY_GAP` (16 px) к краю любой дороги и не ближе `SIGN_CLEAR` к знаку острова. Машина за бордюр не выезжает, луч останавливается на бордюре — поэтому на экране луч сквозь дерево не проходит. Это закреплено тестом `test/engine/scenery.test.mjs`.
- **Расстановка — из seed трассы** (`mulberry32(hashString(id + '|scenery'))`), без `Math.random`: у всех учеников на одной трассе один и тот же лес, скриншоты стабильны, «поворот после большой ели» — общий ориентир.
- `sceneryOf` на путь заезда не попадает: `Car.step`, рой, экзамен, гонка и Worker финала его не вызывают. Считается один раз на трассу, только для рисунка.

## Почему не препятствия

Препятствия — это смена физики: пришлось бы переобучать ботов (`npm run bots`), прогонять `swarm-check`, старые файлы машин поехали бы иначе. Если когда-нибудь понадобятся препятствия, это отдельная игровая механика со своим ADR, а не украшение.

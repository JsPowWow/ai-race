# Интерфейс

- Вкладки: `intro`, `profile` («Профиль»: гараж — полка машин, `profile-garage.tsx`, пересесть = события `car`/`garage`, про неприменённый черновик спрашивает в плитке; облик — имя, цвет, аватар; сборка, форма сети и think черновиком — `profile-build.tsx`, «Применить» зовёт `changeShape()`), `teach` («Я учу»), `train` («Учится само»), `code`, `exam`, `race`, `final` (без кнопки в шапке, открывается из «Гонки»). Старый адрес `#garage` → `teach`.
- Мозг — у выбранной машины гаража: `state.champion` + `state.config` (форма); пересесть — `switchCar()` (событие `car`), у каждой машины свой мозг, «История» и заезды. «Я учу» и рой его сами не меняют (#24): выученное — новый вариант, `propose()` из `app/variants.ts` гонит его на контрольный заезд против твоего мозга (`engine/course/control.ts`), лента попыток и «Взять» — `components/tries.tsx`; первый мозг и «Брать лучшее само» берут сразу. Заменять целиком — через `setBrain()`, форму — через `changeShape()` (с подтверждением, если мозг обнулится), с нуля — `resetBrain()`. Перед каждым таким шагом `remember()` кладёт мозг в «Историю» — не плодить новых режимов и переключателей: интерфейс обучения намеренно минимальный.
- Интерфейс — `@reely/dommy` + TSX (#20). Панель и тулбар вкладки рисует компонент (`mount` в пустой контейнер разметки с `data-panel`/`data-for` — их прячет `main.ts`), а не `innerHTML`: текст вставляется как текст, `esc()` не нужен (исключение — `setHud()`: табло над трассой — HTML-строки, поля для него — `field(подпись, значение)` и `bold()` из `app/ui.ts`, они экранируют сами; пустое `setHud` пропускает). Общие сигналы страницы — `calm` (меньше движения) и `phone` (узкий экран) из `app/ui.ts`; размер холста — `size(canvas)` из `@reely/dommy-kit` (меряет сразу, до первого кадра). Холст, которому после смены темы, размера или шрифтов надо перерисоваться, подписывается сам: `onLook(redraw)` из `app/look.ts` (живое табло мозга — `liveBrain()` из `app/brain-board/live.ts`). Большая вкладка — несколько файлов `tabs/<вкладка>-*.tsx`: состояние и логика (`.ts`, сигналы) отдельно от вида (`.tsx`). Холсты рисует `frame()`. Заезд за одной машиной (твоя, призрак, трафик) — `drawRide(track, scene, 'top' | 'cockpit')` из `app/stage.ts`: одна сцена на оба вида, вкладка не рисует машины сама. Общие компоненты — `app/components/`: `brain-library.tsx` («Мозг» и «История»), `avatar.tsx`, `controls.tsx` (`Seg`, `Select`, `Choice`), `text-with-code.tsx`, `file-button.tsx` (выбрать файлы; JSON-файлы машин читает `eachJsonFile()` из `app/files.ts`), `error-note.tsx` (ошибка с `role=alert`), `tries.tsx` (попытки и «Взять»), `flap-board.tsx` (табло «как в аэропорту»), `stage-flaps.tsx` (оно же у трассы: сбоку или над ней — «Гонка», «Учится само», «Финал»). Новый переиспользуемый кусок интерфейса — туда же. Из `@reely/dommy`: `Keyed` (перестроить кусок, когда сменилось значение); из `@reely/dommy-kit`: `media`, `size`, `throttled`, `later` (таймер, который гасится со следующим запуском effect), `debounced` (вызов «когда утихнет», на уровне модуля; есть `cancel()`/`flush()`), `listen` (тип — один или список: `['pointerup', 'pointercancel']`), `hold` (нажатие с захватом указателя: `hold(el, (down) => ({ move, up }))`), `flip` (`persisted` — только через `stored()`, см. ниже). Стейт-машины в dommy нет и не будет (будет отдельный пакет `@reely/state-machine`) — пока флаги или маленький свой автомат. `select` — выбранное через `selected` у `option` (значение `select` браузер пропустит, пока вариантов нет). Обработчики — camelCase: `onKeyDown`, `onPointerMove`. Общее состояние — через `fromEvents()` (`app/signals.ts`): сигнал, который перечитывается по событиям `state.ts`; своё состояние вкладки — обычные `signal()`. Новое значение из прежнего — `x.update((now) => …)`, а не `x.value = f(x.peek())`. Проверки типов — из `@reely/basics`, а не `typeof` руками: `isPlainObject` (JSON «это объект?», сужает тип — дальше поля читаются как `unknown`), `isString`, `isBoolean`, `isSomeFunction`, `hasSome` (не `null` и не `undefined`). Состояния ARIA — булевы: `aria={{ ariaPressed: on }}`, без `String()`. Текст ошибки для человека — `messageOf(e)`, любое брошенное как `Error` — `toErrorWithMessage(e)` (оба из `@reely/basics`). `Show` отдаёт в ветку своё значение уже без `null`: `<Show when={offer}>{(o) => o().text}</Show>` — без `?.`. Элемент разметки из TS — `element()` (`app/dom.ts`). Подписка на события вне JSX — только `listen()` из `@reely/dommy-kit` (не `addEventListener`): тип события точный, `stop()` вместо `removeEventListener`, внутри компонента снимается вместе с ним. Файлы, брошенные на трассу, — `onTrackDrop()` (`app/stage.ts`). Список, чей порядок меняет логика, а рисует вид (таблицы гонки и финала), — `flipRows()` (`app/components/flip-rows.ts`): вид даёт `elementRef={rows.attach}`, логика меняет порядок через `rows.run(() => …)` — сдвинувшиеся строки переезжают плавно. Настройка, которую надо помнить в браузере (тема, отметки уроков, эпохи), — `stored(key, initial, is)` из `app/storage.ts`: сигнал сам сохраняется и ловит правки из другой вкладки; это `persisted` из kit с нашим префиксом ключа и предупреждением о нехватке места, а `is()` отбрасывает старое и испорченное. Большое (мозги, заезды) — `save()`: он укорачивает дробные числа. Сахар, которого нет в dommy, — сначала спросить сессию reely: библиотека универсальная и минималистичная, прикладное остаётся здесь.
- Разметка — `app/markup.html`. Стили — `app/styles/*.css` по разделам, порядок и каскадные слои — в `app/styles.css` (`tokens, base, layout, stage, components, pages`); без `!important` (исключение — `[hidden]` в base.css).
- Две темы: цвета только через токены из `app/styles/tokens.css` (`light-dark(светлая, тёмная)`), никаких `#fff`/`rgba()` в компонентах. Пластик набора: `--action` (красный — главное действие), `--you` (жёлтый — ты), `--brain` (синий — мозг); у каждого `--x` — заливка, `--x-text` — текст на фоне, `--on-x` — текст на заливке. Облик целиком — `DESIGN.md`. Поверх трассы (HUD, пульт) — всегда тёмное. Холст берёт цвета через `cssColor()` (`engine/draw/render.ts`) и перерисовывается при смене темы.
- Переключатель темы — `app/theme.ts` (авто → светлая → тёмная); проверять обе темы: axe/Lighthouse, контраст AA.
- Телефон 390 px: без горизонтальной прокрутки, на «Я учу» кнопки управления под трассой.
- Тексты уроков — `app/lessons.ts` (простые строки, код — в обратных кавычках, HTML не писать), титульная — `app/markup.html` (фрагмент файла бота строит `app/tabs/intro.tsx`): при переименованиях обновлять оба и README.
- Пользовательский текст в HTML-строках — только через `esc()`; аватары SVG — только через `<img>`/canvas.

# Интерфейс

- Вкладки: `intro`, `profile` («Профиль»: гараж — полка машин, `profile-garage.tsx`, пересесть = события `car`/`garage`, про неприменённый черновик спрашивает в плитке; облик — имя, цвет, аватар; сборка, форма сети и think черновиком — `profile-build.tsx`, «Применить» зовёт `changeShape()`), `teach` («Я учу»), `train` («Учится само»), `code`, `exam`, `race`, `final` (без кнопки в шапке, открывается из «Гонки»). Старый адрес `#garage` → `teach`.
- Мозг один на весь сайт: `state.champion` + `state.config` (форма). Учёба всегда продолжает текущий мозг. Заменять целиком — через `setBrain()`, форму — через `changeShape()` (с подтверждением, если мозг обнулится), с нуля — `resetBrain()`. Перед каждым таким шагом `remember()` кладёт мозг в «Историю» — не плодить новых режимов и переключателей: интерфейс обучения намеренно минимальный.
- Интерфейс — `@reely/dommy` + TSX (#20). Панель и тулбар вкладки рисует компонент (`mount` в пустой контейнер разметки с `data-panel`/`data-for` — их прячет `main.ts`), а не `innerHTML`: текст вставляется как текст, `esc()` не нужен (исключение — `setHud()`: табло над трассой — HTML-строки). Большая вкладка — несколько файлов `tabs/<вкладка>-*.tsx`: состояние и логика (`.ts`, сигналы) отдельно от вида (`.tsx`). Холсты рисует `frame()`. Общие компоненты — `app/components/`: `brain-library.tsx` («Мозг» и «История»), `avatar.tsx`, `controls.tsx` (`Seg`, `Select`, `Choice`), `keyed.tsx` (перестроить кусок, когда сменилось значение), `text-with-code.tsx`, `flap-board.tsx` (табло «как в аэропорту»). Новый переиспользуемый кусок интерфейса — туда же. Состояние страницы сигналом (медиазапрос, размер элемента) — `app/dom-signals.ts`. `select` — выбранное через `selected` у `option` (значение `select` браузер пропустит, пока вариантов нет). Обработчики — `onKeydown`, `onPointermove` (так в dommy). Общее состояние — через `fromEvents()` (`app/signals.ts`): сигнал, который перечитывается по событиям `state.ts`; своё состояние вкладки — обычные `signal()`. Элемент разметки из TS — `element()` (`app/dom.ts`). Сахар, которого нет в dommy, — сначала спросить сессию reely: библиотека универсальная и минималистичная, прикладное остаётся здесь.
- Разметка — `app/markup.html`. Стили — `app/styles/*.css` по разделам, порядок и каскадные слои — в `app/styles.css` (`tokens, base, layout, stage, components, pages`); без `!important` (исключение — `[hidden]` в base.css).
- Две темы: цвета только через токены из `app/styles/tokens.css` (`light-dark(светлая, тёмная)`), никаких `#fff`/`rgba()` в компонентах. Пластик набора: `--action` (красный — главное действие), `--you` (жёлтый — ты), `--brain` (синий — мозг); у каждого `--x` — заливка, `--x-text` — текст на фоне, `--on-x` — текст на заливке. Облик целиком — `DESIGN.md`. Поверх трассы (HUD, пульт) — всегда тёмное. Холст берёт цвета через `cssColor()` (`engine/render.ts`) и перерисовывается при смене темы.
- Переключатель темы — `app/theme.ts` (авто → светлая → тёмная); проверять обе темы: axe/Lighthouse, контраст AA.
- Телефон 390 px: без горизонтальной прокрутки, на «Я учу» кнопки управления под трассой.
- Тексты уроков — `app/lessons.ts` (простые строки, код — в обратных кавычках, HTML не писать), титульная — `app/markup.html` (фрагмент файла бота строит `app/tabs/intro.tsx`): при переименованиях обновлять оба и README.
- Пользовательский текст в HTML-строках — только через `esc()`; аватары SVG — только через `<img>`/canvas.

# Интерфейс

- Вкладки: `intro`, `profile` («Профиль»: гараж — полка машин, `profile-garage.js`, пересесть = события `car`/`garage`, про неприменённый черновик спрашивает в плитке; облик — имя, цвет, аватар; сборка, форма сети и think черновиком — «Применить» зовёт `changeShape()`), `teach` («Я учу»), `train` («Учится само»), `code`, `exam`, `race`, `final` (без кнопки в шапке, открывается из «Гонки»). Старый адрес `#garage` → `teach`.
- Мозг один на весь сайт: `state.champion` + `state.config` (форма). Учёба всегда продолжает текущий мозг. Заменять целиком — через `setBrain()`, форму — через `changeShape()` (с подтверждением, если мозг обнулится), с нуля — `resetBrain()`. Перед каждым таким шагом `remember()` кладёт мозг в «Историю» — не плодить новых режимов и переключателей: интерфейс обучения намеренно минимальный.
- Разметка — `app/markup.html`. Стили — `app/styles/*.css` по разделам, порядок и каскадные слои — в `app/styles.css` (`tokens, base, layout, stage, components, pages`); без `!important` (исключение — `[hidden]` в base.css).
- Две темы: цвета только через токены из `app/styles/tokens.css` (`light-dark(светлая, тёмная)`), никаких `#fff`/`rgba()` в компонентах. Пластик набора: `--action` (красный — главное действие), `--you` (жёлтый — ты), `--brain` (синий — мозг); у каждого `--x` — заливка, `--x-text` — текст на фоне, `--on-x` — текст на заливке. Облик целиком — `DESIGN.md`. Поверх трассы (HUD, пульт) — всегда тёмное. Холст берёт цвета через `cssColor()` (`engine/render.ts`) и перерисовывается при смене темы.
- Переключатель темы — `app/theme.js` (авто → светлая → тёмная); проверять обе темы: axe/Lighthouse, контраст AA.
- Телефон 390 px: без горизонтальной прокрутки, на «Я учу» кнопки управления под трассой.
- Тексты уроков — `app/lessons.js`, титульная — `app/markup.html`: при переименованиях обновлять оба и README.
- Пользовательский текст в HTML — только через `esc()`; аватары SVG — только через `<img>`/canvas.

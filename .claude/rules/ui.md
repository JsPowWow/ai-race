# Интерфейс

- Вкладки: `intro`, `teach` («Я учу»), `train` («Учится само»), `code`, `exam`, `race`, `final` (без кнопки в шапке, открывается из «Гонки»). Старый адрес `#garage` → `teach`.
- Мозг один на весь сайт: `state.champion` + `state.config` (форма). Заменять целиком — через `setBrain()` (прежний уходит в «↶ Вернуть»), форму менять — через `changeShape()`. В библиотеку — только по кнопке.
- Разметка — `app/markup.html`, стили — `app/styles.css` (одна тёмная тема, токены в `:root`). Телефон 390 px: без горизонтальной прокрутки, на «Я учу» кнопки управления под трассой.
- Тексты уроков — `app/lessons.js`, титульная — `app/markup.html`: при переименованиях обновлять оба и README.
- Пользовательский текст в HTML — только через `esc()`; аватары SVG — только через `<img>`/canvas.

# AI Race

Машинки учатся ездить сами: маленькая нейросеть и эволюция на чистом JavaScript.
Пять коротких уроков и финальная гонка на секретной трассе со встречными машинами.

**Играть:** https://jspowwow.github.io/ai-race/

## Уроки

| Вкладка | Урок | О чём |
|---|---|---|
| Гараж | 1. Глаза и мозг машины | сенсоры, нейрон, веса и пороги; ручная правка весов |
| Учитель | 2. Повторяй за мной | обучение с учителем: примеры, ошибка, шаг обучения |
| Трек | 3. Эволюция | поколения, фитнес, отбор, мутация, кроссовер |
| Код | Мастерская | пять функций, которые пишут студенты |
| Экзамен | 4. Выучил или понял? | переобучение и обобщение |
| Гонка | 5. Гонка | секретная трасса, номинации, гибриды |
| Финал | для кураторов | общая гонка на сотни участников: этапы, суперфинал, стрим |

Чистый адрес сайта открывает титульную страницу: о чём курс, как устроена нейросеть и как проходят уроки. Над каждой вкладкой — карточка урока: цель, задание с галочками, что изучаем и как это влияет на гонку.

## Задания

Всё, что пишут студенты, лежит в `student/`. Проверки к каждому файлу — на вкладке «Код»:
**OK** — работает, **Совет** — можно лучше, **Ошибка** — надо чинить.

1. `controls.js` — ручное управление: события клавиатуры.
2. `think.js` — свой вариант «мозга».
3. `mutate.js` — как встряхнуть веса лучшей машины.
4. `fitness.js` — за что хвалить машину.
5. `crossover.js` — ребёнок от двух родителей.

В файлах лежат простые рабочие версии: с ними машина «кое-как» доезжает. Если хотите, чтобы писали с нуля, замените тела функций на `// TODO`.

## Запуск

Сборщик не нужен — это обычные ES-модули.

```
npm start          # любой статический сервер: npx serve .
```

Или откройте `index.html` через Live Server в VS Code.

## Как устроен код

```
student/     код студентов — единственное, что их просят менять
engine/      мир без интерфейса: трассы, машина, трафик, сеть, эволюция, обучение на примерах, рисование
app/         интерфейс
  main.js         точка входа: вкладки и кадровый цикл
  state.js        общее состояние, сохранение и события между вкладками
  stage.js        холст: камера, сцена, HUD, баннер
  car-file.js     файл машины: собрать свой, подготовить чужой (проверка — engine/car-file.js)
  countdown.js    отсчёт «3 — 2 — 1 — СТАРТ!»
  download.js     сохранение файлов
  final/          финал курса: загрузка работ, Web Worker для расчёта, показ записи, экспорт итогов
  student-code.js код студентов: исходный или отредактированный во вкладке «Код»
  tests.js        проверки кода студентов
  lessons.js      тексты уроков
  manual-drive.js ручное управление: клавиатура и кнопки на экране
  tabs/           по файлу на вкладку: intro, garage, network-editor, teach, train, code, exam, race, final
tools/       сборка и эксперименты в Node
```

Правила, на которых всё держится:

- **`engine/` не знает про страницу.** Его можно запускать в Node — так обучаются боты и проводятся эксперименты.
- **Вкладки не импортируют друг друга.** Они общаются через `state.js`: `setChampion()`, `resetProgress()` и события `champion`, `reset`, `code`.
- **Время — в тиках, а не в секундах.** Трафик зависит только от номера тика, поэтому у всех участников гонки одинаковый мир, а скорость компьютера ни на что не влияет.

## Безопасность: как выполняется код студентов

Код с вкладки «Код» превращается в функцию (`new Function`) и выполняется прямо на странице. Это **не песочница**: такой код может всё, что может сама страница.

- **Свой код — только в своём браузере.** Правки хранятся в `localStorage` и никуда не отправляются. Навредить студент может только себе.
- **Чужой код на гонке не запускается сам.** Если в файле участника есть свой вариант мозга (`thinkSource`), на вкладке «Гонка» появляется кнопка «Свой код — проверить». Преподаватель видит код, подозрительные строки подсвечены (обращения к странице, сети, хранилищу, `constructor`, бесконечные циклы, подмена `Math`). Без «Разрешить» машина в гонке не участвует. Файлы без своего кода — это только числа, они проверяются по формату и безопасны.
- **Защита от случайностей.** В коде студента имена `window`, `document`, `fetch`, `localStorage`, `Function` и др. подменены на `undefined`. Это защищает от случайностей и простых шалостей, но не от взлома — обойти можно.
- **Защита от зависания.** Если код завис (например, `while (true)`), после перезагрузки страницы правки отключаются и возвращаются исходные файлы.
- **Финал: чужой код — в Web Worker.** На сотни файлов ручная проверка не работает, поэтому на вкладке «Финал» свой вариант мозга участника выполняется в отдельном Worker: там нет страницы, хранилища и cookies. Перед запуском чужого кода у Worker отнимаются сеть и `postMessage`, закрыт путь к глобальному объекту через конструктор функций, заморожены `Math` и прототипы (чтобы нельзя было испортить мир следующим участникам). Код, который думает дольше 5 секунд, снимается с гонки.
- **Аватар** — SVG до 8 КБ. Он показывается только через `<img>` и на canvas, а в таком виде браузер не выполняет скрипты и не ходит в сеть. Скрипты, `on…=` и внешние ссылки дополнительно отбрасываются при проверке файла. На вкладке «Финал» есть галерея аватаров: неподходящие можно скрыть перед стримом.

## Финал курса

Вкладка «Финал» открывается со вкладки «Гонка» (или по адресу `#final`). Она для кураторов: общая гонка на 300–500 участников и стрим.

**Формат.** Три этапа на секретных трассах и суперфинал первой десятки. В зачёт идёт сумма времени трёх этапов. Не доехал — штраф: лимит времени × (2 − доля трассы), поэтому любой финиш лучше любого схода, а из сошедших выше тот, кто проехал дальше. Одинаковый результат — одно место. Номинации: победитель, быстрее всех на каждом этапе, самая эпичная авария, самый плавный ход, «чуть-чуть не хватило».

**Почему результат известен заранее.** Трассы строятся из секретной фразы, трафик — формула от номера тика, сеть — готовые числа, физика идёт фиксированными тиками. Поэтому все заезды считаются заранее за секунды (машины друг другу не мешают), а на стриме показывается запись. После гонки объявите фразу — любой повторит свой заезд у себя: вкладка «Гонка», свой файл, seed вида `фраза · этап 1`.

**Как провести:**

1. **Собрать работы.** Студент скачивает `car.json` на «Экзамене» (веса, имя машины, цвет, по желанию SVG-аватар) и сдаёт пул-реквестом. Лучше — в свой приватный репозиторий: в общем репозитории лучшие веса быстро разойдутся по рукам.
   - Список ссылок на PR (например, выгрузка сабмитов) → `node tools/collect-entries.mjs prs.txt entries`. Нужен `gh auth login` с доступом к репозиториям. Получится папка `entries/<логин автора PR>/car.json`.
   - GitHub Classroom → `gh classroom clone student-repos`. Общий префикс папок (`ai-race-final-…`) отрежется сам.
2. **Открыть папку** на вкладке «Финал». Там же видно замечания к файлам, группы одинаковых мозгов (они делят место — обычно это копия или несданный «по умолчанию» мозг) и галерея аватаров.
3. **Придумать фразу и нажать «Посчитать финал».** 500 участников × 4 трассы — несколько секунд на обычном ноутбуке.
4. **Шоу.** «Трансляция» — на весь экран только трасса и таблица. Этап за этапом: «Старт этапа» → отсчёт → гонка. Сотни машин едут полупрозрачными, первая десятка — ярко, первая тройка подписана; внизу полоса прогресса: каждый участник — точка. Поиск по нику подсвечивает машину и её строку. После этапа — общий зачёт со стрелками ▲▼.
5. **Итоги.** После суперфинала — номинации и файлы: `RESULTS.md` (положить в репозиторий), `.csv` (для баллов), `results.json`.

**Репетиция:** `node tools/make-demo-entries.mjs 300 demo-entries` создаёт папку с выдуманными работами — с копиями, аватарами, своим кодом, зависшим кодом и битым файлом.

## Что хранится в браузере

Всё сохраняется в `localStorage` браузера: настройки, лучший мозг, график, зал чемпионов, правки кода, записи «Учителя». На сервер ничего не уходит.

Места там мало — около 5 МБ на сайт, и его делят все проекты на `jspowwow.github.io`. AI Race занимает обычно десятки–сотни КБ:

| Что | Размер |
|---|---|
| мозг 6 → 6 → 4 / самый большой 16 → 16 → 16 → 16 → 4 | ~1 КБ / ~13 КБ |
| зал чемпионов (8 мозгов) | до ~110 КБ |
| график (последние 300 поколений) | ~100 КБ |
| записи «Учителя» (до 8000 примеров, упакованы по символу на число) | до ~160–300 КБ |

Числа сохраняются с 5 знаками после запятой. Если место всё-таки кончится, страница не падает: появится сообщение, а новые данные просто не сохранятся до перезагрузки.


Вкладка «Финал» в браузере ничего не хранит: работы участников и результаты живут только в памяти открытой вкладки.
## Для преподавателя

```
npm run build      # собрать dist/ai-race.html — всё в одном файле
npm run lint       # проверить код
npm run bots       # заново обучить ботов-соперников (несколько минут)
npm run compare    # эксперимент: помогает ли кроссовер (1 родитель против 2)
npm run demo       # папка demo-entries с выдуманными работами для репетиции финала
```

- **Гонка:** загрузите файлы участников на вкладке «Гонка», объявите seed и нажмите «Старт». По одному seed трасса одинакова на любом компьютере. Для большого финала — вкладка «Финал» (см. выше).
- **Число полос** — `LANES` в `engine/track.js`. **Трафик** — `engine/traffic.js`: левая полоса встречная, остальные попутные. После изменений переобучите ботов.
- **Публикация:** GitHub Pages раздаёт сайт прямо из ветки `main` (Settings → Pages → Deploy from a branch → `main`, папка `/`). Сборка не нужна, каждый push сразу попадает на сайт.

# engine/ — движок по слоям

Движок — мир без страницы: его запускают вкладки, Web Worker финала, тесты и скрипты в `tools/` (Node).
Он разложен по слоям — будущим пакетам. Слой берёт только из тех, что ниже, поэтому любой нижний
можно вынести отдельно и сделать на нём другую игрушку про машинки и трассы. Правило проверяет
`test/engine/layers.test.mjs`.

| Слой | Что внутри | Берёт из | Страница |
|---|---|---|---|
| `core/` | математика и seed (`utils.ts`), точка (`geometry.ts`), наклонный вид (`tilt.ts`), оттенки цвета (`paint.ts`) | — | нет |
| `net/` | мозг: веса, форма сети, `think`, входы и выходы (`brain.ts`) | core | нет |
| `world/` | трассы (`turtle.ts` рисует путь, `track.ts` строит), машина и сенсоры (`car.ts`), трафик, декор (`scenery.ts`), ралли финала (`rally.ts`) | core, net | нет |
| `learn/` | рой (`evolution.ts`, `recipes.ts`), обучение на примерах (`imitation.ts`) | core, net, world | нет |
| `course/` | правила курса: файл машины, цена сборки, контрольный заезд, печать для куратора, код студента | core, net, world, learn | нет |
| `draw/` | холст: трасса сверху (`render.ts`, `scenery-draw.ts`, `track-cache.ts`), машины (`car-draw.ts`), картинка сети (`netviz.ts`), вид из машины (`cockpit/`) | core, net, world | canvas |
| `sound/` | счёт звука мотора (`motor.ts`); звучит `app/engine-sound.ts` | core, world | нет |

Что из этого может стать пакетом:

- **core + world** — «трасса с машинкой»: кольцо из seed, физика, сенсоры, трафик, декор. Без сети: `think` машины — любая функция.
- **net + learn** — маленькая нейросеть и как её учить (рой, примеры) для любого мира с `Car.step`.
- **draw** — игрушечный стол сверху и вид из машины для того же мира.
- **course** — только этот курс: файл машины, бюджет, печать. Остаётся здесь.

Правила, общие для всех слоёв:

- Детерминизм: время в тиках, трафик — функция тика, всё случайное — из seed (`mulberry32` + `hashString`).
  Никакого `Math.random`/`Date` на пути заезда.
- Без `window`, `document`, `localStorage` (кроме `draw/`, и тот только рисует на переданном холсте).
- Новый файл — в подходящий слой; если нужен тип из слоя выше, значит, тип лежит не там: опусти его вниз (так `Point` живёт в `core/`).
